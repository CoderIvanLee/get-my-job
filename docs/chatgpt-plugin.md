# ChatGPT 插件打包与使用

插件名称：向职 · AI 求职助手。版本：`0.1.0`。

包含四个技能：`qz-profile`、`qz-job-fit`、`qz-project-coach`、`qz-interview-coach`。

## 打包

```bash
python3 tools/package_career_plugin.py
```

生成 `docs/xiangzhi-ai-career-plugin.zip`，从 `.claude/skills/qz-*/SKILL.md` 读取规范，不维护第二套技能正文。压缩包是插件源文件，不代表已经安装到使用者的 ChatGPT 账户。请通过账户可用的插件创建或导入能力安装；具体入口以账户实际界面为准。

## 聊天使用

安装后，在支持插件的 ChatGPT 聊天中选择「向职 · AI 求职助手」或对应技能，再提出任务。例如：

> 只使用 AI 面试教练，把下面的项目介绍改成 30 秒英文自我介绍，不进行模拟面试：……

已有聊天可能需要新建后才能加载新插件。此插件不自动读取本地网站的求职档案；请在聊天中提供资料或上传所需文件。

插件无 MCP 或外部服务依赖。联网、代码运行、语音和保存能力由聊天宿主决定。修改技能后，重新打包并更新已创建的插件。

发布到公共仓库时，不要包含账户私有插件链接、插件标识、发布标识、个人求职资料或模型密钥。
