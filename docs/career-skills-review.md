# 四个 AI 求职 Skill 审查报告

> 历史审查：以下行号对应 `3c943db`，不是当前修订版。R1–R10 的落实位置与场景试用结果见 [改进验证记录](career-skills-improvement-verification.md)。

审查对象：提交 `3c943db` 的四份规范，共 111 行。方法：静态逐句审查与输入场景推演；未进行独立模型行为实测。

结论：每个业务段落有明确目标，但“有目的”不等于“表达充分”。发现 8 项 P2、2 项 P3，无需重写整体框架。建议先修任务分流、分类口径和证据状态，再补 Agent 验收与会话结束条件。

本报告仅审查，不修改 Skill 原文、入口或分发包。

“保留”表示该句有独立作用；“合并”表示保留约束但减少重复；“改写”表示目的有效、现有表述会引起偏差。结构行保留，不把标题与 YAML 当作可删除的废话。不同 Skill 内的相似规则不自动算重复：每个包必须能独立使用。
